# Графика NOVA

Главное изображение создано встроенным ImageGen 4 ноября 2026 года для редизайна этого проекта.

Файл: `nova-orbit.webp`. Для сборки проекта используется его копия в формате data URL: `nova-orbit-data.txt`. В изолированном предпросмотре изображение встраивается без сетевых разрешений. В экспортированном ZIP и независимом NOVA оно сохраняется отдельным файлом `assets/nova-orbit.webp`.

Исходный промпт:

> Use case: stylized-concept. Asset type: main artwork for a contemporary technology festival website named NOVA. Generate a premium art-directed 3D studio render, portrait 4:5 composition. One sculptural polished liquid-chrome orbital knot made of thick looping tubular ribbons, intertwined with a translucent deep violet glass ring, floating above a dark almost-black reflective floor. The central chrome object is large and sculptural, like high-end experimental typography but NOT a readable letter. Strong silver highlights, violet and faint electric lavender reflections, crisp material realism, raytraced lighting, soft volumetric purple glow. Background is a perfectly clean deep ink-purple (#171020) with subtle studio light falloff. Sophisticated creative coding / digital culture festival visual, gallery-quality CGI. Frame the entire sculpture with comfortable negative margins of 12 percent, centered. No people, no faces, no headset, no text, no letters, no words, no logo, no watermark, no UI elements. Output should feel like a premium contemporary design studio campaign, never a cartoon.

Применён встроенный инструмент ImageGen, без CLI или внешнего API-ключа. После генерации выполнен экспорт в WebP для уменьшения размера без изменения композиции.
