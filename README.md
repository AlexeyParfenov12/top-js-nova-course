# TOP — JavaScript: оживи сайт NOVA

Образовательная платформа без регистрации и сервера: 3 дня, 9 пар по 90 минут, 18 упражнений, один развивающийся семистраничный сайт фестиваля.

## Запуск

Требуется Node.js 24 LTS и npm.

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite, с окончанием `/top-js-nova-course/`. Основная навигация использует `#/`, поэтому обновление вложенных страниц работает на GitHub Pages.

```sh
npm test
npx playwright install chromium
npm run test:e2e
npm run build
npm run preview
```

## Возможности

- Раздельные TOP (обучение) и NOVA (проект): программа, лекции, тренажёры, практика и проект.
- 27 разделов теории, 9 пошаговых демонстраций, 9 лабораторий с изменяемыми данными, 18 проверяемых упражнений, 9 практических этапов, трёхуровневые подсказки и открытые эталоны.
- Monaco с локальными workers: подсветка, диагностика JavaScript, автодополнение, поиск Ctrl+F, отмена Ctrl+Z, повтор Ctrl+Y, дерево и вкладки файлов. Ctrl+Enter запускает предпросмотр. Никаких CDN для редактора.
- Режимы обучения и разработки, скрываемые панели, изменение ширины редактора, размера инструкции и консоли. HTML и CSS доступны для чтения в заданиях и для редактирования в свободном проекте.
- Реальные функциональные проверки DOM, событий, функций и границ ввода. Перед применением этапа проверяются ранее добавленные этапы. Задания — изолированные черновики.
- IndexedDB: черновики, упражнения, текущая пара, результаты, проект и последние 30 контрольных точек. JSON переносит прогресс между устройствами. Перед импортом и полным сбросом требуется подтверждение внутри интерфейса.
- Семь страниц NOVA, сравнение с эталоном с начала обучения, независимый ZIP с HTML, CSS и JS, без внешних библиотек и сетевых ресурсов. Отдельный эталон опубликован в подпапке `nova/`; он генерируется перед запуском и сборкой из тех же исходников.
- Оригинальная графика SVG/CSS, адаптивные экраны, клавиатурная навигация, сообщения aria-live. Графика создана по направлению пользовательских референсов, без извлечения чужих фотографий.

## Публикация и обновление

Ожидаемый репозиторий: `AlexeyParfenov12/top-js-nova-course`. Адрес после успешного deployment: `https://alexeyparfenov12.github.io/top-js-nova-course/`. Само наличие адреса в README не подтверждает публикацию: статус смотрите в Actions и Settings → Pages.

В Settings → Pages выберите Source → GitHub Actions. Workflow `GitHub Pages` запускается при push в `main` и вручную. Он выполняет `npm ci`, unit-тесты, production-сборку, браузерные тесты, загружает `dist` и публикует artifact. Разрешения: `contents: read`, `pages: write`, `id-token: write`. Все версии официальных Actions проверены при создании проекта 4 ноября 2026 года.

Если создаёте репозиторий самостоятельно:

```sh
git init -b main
git add .
git commit -m "Build TOP JavaScript Academy and NOVA course"
git remote add origin https://github.com/AlexeyParfenov12/top-js-nova-course.git
git push -u origin main
```

Перед использованием этих команд убедитесь, что удалённый репозиторий пуст. Для обновления существующего проекта: `git add .`, `git commit`, `git push`. Публикуется только успешно проверенная сборка. Если имя репозитория меняется, обновите `base` в `vite.config.ts` и адреса браузерных тестов.

## Границы продукта

Это учебный сайт: NOVA не продаёт билеты, не бронирует места и не отправляет сообщения. Форма явно сообщает о локальной проверке. Даты, участники и адрес электронной почты демонстрационные. Локальные тесты открыты и не являются защищённой экзаменационной системой.

Данные привязаны к браузеру и origin; очистка данных сайта удалит IndexedDB. Для резервной копии нужен экспорт JSON. Восстановление проекта из контрольной точки не изменяет учебные черновики.

Разбор AST и ограничение времени защищают от типичных случайных циклов и рекурсии; это не полноценный вычислительный контейнер для намеренно враждебных программ. Изоляцию данных TOP обеспечивает iframe без `allow-same-origin` и CSP, запрещающая сеть. Поддержка языков редактора шире, чем текущий курс: учебный runner сейчас исполняет обычный браузерный JavaScript; для TS/JSX потребуется отдельный этап компиляции.
