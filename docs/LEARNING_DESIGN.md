# Дизайн курса и объём занятий

Обновление 4 ноября 2026 года касается учебной платформы TOP. Самостоятельный NOVA остаётся проектом, который ученик постепенно оживляет.

## Изученные источники

- [HTML Academy: введение в веб-разработку](https://htmlacademy.ru/courses/intro-to-web-development): публичная программа с небольшими разделами, разделением теории и практики, заданиями и ориентирами времени.
- [Codecademy: Introduction to JavaScript](https://www.codecademy.com/learn/introduction-to-javascript): обзор результата обучения, программа, уроки, проекты и контрольные вопросы, возможность двигаться в собственном темпе.
- [Scrimba: Learn JavaScript](https://scrimba.com/learn-javascript-c0v) и [официальные материалы об интерактивном JavaScript](https://docs.scrimba.com/javascript/async): изменение кода и самостоятельная практика внутри учебного процесса. Страница каталога динамическая; наблюдения об интерактивности опираются на официальную документацию.

Публичные страницы HTML Academy и Codecademy также просмотрены визуально. Это исследование интерфейсов и структуры, а не полный аудит платных программ. Тексты, задания, графика и код этих сервисов не переносились.

## Формат занятия с преподавателем

Страница пары показывает три части и время на каждую. Лекция начинается с задачи, затем последовательно объясняет три понятия на небольших примерах, показывает ожидаемый результат рядом с кодом, разбирает заготовки тренажёра и практики и завершает разбором ошибок. Оглавление позволяет вернуться к нужному разделу. В тренажёре открыта одна из двух связанных задач. В практике группа применяет тему к одному этапу NOVA. В окне задания есть три шага работы. Код предыдущих этапов подхватывается автоматически.

| Время | Что делает группа |
| --- | --- |
| 0–5 мин | Смотрит результат пары и формулирует цель |
| 5–17 мин | Разбирает три идеи, по четыре минуты на каждую |
| 17–27 мин | Разбирает заготовки тренажёра и практики, смотрит ожидаемый результат |
| 27–30 мин | Разбирает типичные ошибки и готовится к тренажёру |
| 30–55 мин | Решает первую задачу вместе, вторую самостоятельно и разбирает результат |
| 55–78 мин | Читает условие NOVA и собирает первый рабочий вариант вместе |
| 78–90 мин | Завершает, проверяет и показывает результат |

Этот план раскрывается над конспектом каждой пары. Подсказки к живому примеру, вопросы и ручная проверка результата зависят от темы. Длительность рассчитана для группы с преподавателем. Фактический темп можно уточнить после первого проведения.
