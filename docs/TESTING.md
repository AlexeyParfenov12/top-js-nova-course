# Проверки

- Vitest + React Testing Library: полнота курса, структура экспортируемых страниц и ссылок, корректность AST-инструментации циклов/рекурсии, синтаксические ошибки, импорт прогресса, проверка сообщений и доступный progressbar.
- Playwright: все 9 эталонов и неверные черновики; 18 решений упражнений; остановка случайного бесконечного цикла; синтаксические ошибки; намеренная регрессия.
- Полный UI-путь: неправильное решение → Monaco → загрузка эталона → функциональная проверка → добавление этапа с регрессиями, 9 раз → перезагрузка и IndexedDB → 100% проекта → ZIP → распаковка → независимые HTML-страницы и интерактивность без платформы.
- Теория и пошаговая демонстрация; ввод ответа в тренажёр; экспорт/импорт JSON; отказ от повреждённых данных; сброс с подтверждением и восстановление.
- Ширины 1920, 1440, 1366, 900, 768 и 390 px: отсутствие горизонтального переполнения и скриншоты главной.
- Прямой ввод JavaScript клавиатурой в Monaco, сохранение, выполнение, вывод console.log и восстановление кода после перезагрузки.
- Лаборатории с изменением заголовка и фильтра, независимый эталон в `nova/` с переходами между HTML-страницами.

Команды приведены в README. Отчёт Playwright создаётся в `playwright-report/`, подробности и скриншоты — в `test-results/`; они не коммитятся. Для CI Chromium устанавливается через `npx playwright install --with-deps chromium`.

Проверка правильности всех учебных эталонов использует исходные модули через локальный Vite. Для опубликованной production-версии отдельно проверяются загрузка ассетов, маршруты, редактор, эталон, работа кнопок и отсутствие ошибок путей. Не пытайтесь запускать исходный harness `/src` на статической production-сборке.

Последняя локальная проверка перед публикацией: **13/13 Vitest, 6/6 Playwright**, production-сборка успешна. Браузерные сценарии завершились за 27 секунд на компьютере разработки. Проверка опубликованного сайта: `node scripts/verify-production.mjs https://alexeyparfenov12.github.io/top-js-nova-course/`.
