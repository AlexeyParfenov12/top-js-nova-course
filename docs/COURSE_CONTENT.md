# Как добавлять и заменять материалы

## Новая лекция в существующей структуре

Добавьте запись Lesson в `src/content/course.ts`: id, day, title, goal, sections (заголовок, объяснение, код, замечание), demo (строки и состояния), exercises (условие, черновик, решение, тесты, подсказка), task, requirements, три hints, solution, tests, summary и page NOVA. Материалы не должны содержать JSX.

Существующий выпуск рассчитан ровно на 9 этапов и 3 дня. Если расширяете число занятий, обновите валидацию идентификаторов в persistence.tsx, пределы навигации Workspace/Lesson, счётчики Home/Project и тест полноты курса. Компоненты теории и редактора переиспользуются; числовые ограничения текущего курса должны быть перенесены в новый манифест при добавлении второго курса.

`demo.code` содержит шаги, `demo.states` — состояние до первого и после каждого шага. Количество состояний равно количеству строк + 1. Пошаговая иллюстрация объясняет ход выполнения, а реальное выполнение кода происходит в практике и упражнениях.

## Замена практического задания

1. Сохраните контракты DOM: селекторы, структуру данных и общие функции, на которые опираются следующие этапы, либо согласованно измените следующие задания.
2. Замените starter, task, requirements, hints, solution и tests одной записи.
3. В tests используйте `test('Сценарий', () => { ... })`, `q(selector)`, `equal(actual, expected)` и `ok(condition, message)`. Проверяйте результат, а не подстроки исходного кода.
4. Добавьте разные входные значения, пустые и неверные данные, повторные клики/рендеры. Не называйте эти тесты скрытыми.
5. Эталон должен работать и на целевой странице, и безопасно пропускать нерелевантные страницы.
6. Выполните `npm test`, `npm run test:e2e`, `npm run build`. Тесты браузера автоматически проходят решения всех занятий, отвергают starter, проверяют упражнения и экспорт.

При несовместимом изменении данных поднимите версию схемы Progress и добавьте миграцию старых сохранений. Не удаляйте данные молча.

## Будущие курсы HTML, CSS, SCSS, React и TypeScript

Редактор уже выбирает языки по расширениям файлов. Для второго курса выделите манифест: courseId, lessons, projectAdapter, executionAdapter и gradingAdapter. Используйте отдельный ключ IndexedDB по courseId. Редактор, вкладки, прогресс и UI результатов остаются общими.

HTML/CSS: адаптер собирает документ из редактируемых файлов, проверяет DOM и computedStyle в iframe. SCSS: добавьте локальный компилятор Sass перед сборкой документа. TypeScript/JSX/TSX: добавьте локальную компиляцию и ограниченный resolver зависимостей, затем исполняйте результат в том же iframe. React потребует подготовленного рантайма в preview; основной TOP не должен предоставлять кодам ученика своё окно или origin. Произвольные npm-пакеты в браузере автоматически не поддерживаются.

Новые курсы в текущем выпуске не реализованы. Необходимо отдельно создать их учебные материалы, задания, тесты и адаптеры компиляции.
