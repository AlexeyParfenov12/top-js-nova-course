# Архитектура

`src/app` — оболочка React и маршруты HashRouter. `src/pages` — домашняя страница, программа, лекция, практика, проект и данные. Редактор загружается лениво, чтобы домашняя страница не ожидала Monaco.

`src/content/types.ts` задаёт контракт урока, упражнения, результата и прогресса. `src/content/course.ts` содержит материалы всех девяти занятий отдельно от UI. Компоненты не анализируют текст решения для выставления результата.

`src/projects/nova.ts` — генератор семи автономных HTML-файлов, CSS, исходных данных и JS-файлов этапов. Один набор исходников обслуживает эталон, предпросмотр и ZIP. Студенческая версия начинается с готового HTML/CSS и пустых функций. Эталон состоит из девяти решений.

`src/engine/execution.ts` реконструирует документ предпросмотра и исполняет код только в sandbox iframe с `allow-scripts`, без same-origin. CSP запрещает сеть, внешние скрипты, формы и base-uri. Сообщения проверяются по `event.source`, `origin === 'null'`, каналу, случайному nonce, типу и формату. Сообщения ограничены по количеству и длине. Родитель не использует eval/Function для кода ученика.

`instrument.ts` разбирает код Acorn и вставляет watchdog в циклы и функции. Стандартный бюджет — 250 мс; для синхронного набора тестов — 1000 мс. Проверка снимает iframe через 4 секунды, если ответа нет; проверки выполняются последовательно через очередь. Размер отдельного файла ограничен 100 000 символов. Это защита от случайных ошибок новичков, не от произвольного злонамеренного кода.

Функциональные тесты используют события и утверждения над DOM. Перед применением этапа они повторяются для всех уже добавленных функций на соответствующих страницах. Изменение черновика делает предыдущий успешный результат неприменимым. Во время проверки редактор заблокирован, чтобы не применить непроверенное состояние.

`persistence.tsx` — контекст состояния и последовательные транзакции IndexedDB. `drafts` отделён от `codes`: текущая практика не изменяет основной проект до успешных проверок. `files` хранит переопределения свободного редактора. Контрольная точка сохраняет `codes` и `files`. Импорт проходит проверку версии, путей, типов и размеров.

`export.ts` — JSON и ZIP через JSZip. Экспортированный NOVA не использует React, TOP или IndexedDB. Сценарии подключены с defer, этапы обёрнуты в отдельные области видимости; функции между этапами публикуются явно в window. Для элементов каждой страницы используются проверки существования.
